# Business Promotion — Vite

A small marketing landing site built with Vite.

## Quick start

Requirements:

- Node.js 16+ (or current LTS)
- npm (or yarn/pnpm)

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build locally:

```bash
npm run preview
```

## Project structure

- `index.html` — main entry page
- `src/main.js` — client bootstrap
- `src/css/` — stylesheets used across pages
- `src/partials/` — HTML partials included in pages
- `src/img/` — image assets (organized by subfolders)
- `pricing-page.html`, `resources.html`, `customers.html` — other pages

## Notes

- This project uses Vite for fast local development and production builds.
- If your `package.json` uses different script names, replace the commands above accordingly.
